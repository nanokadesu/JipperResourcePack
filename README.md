### Introduction

JipperResourcePack adds a range of useful features to the A Dance of Fire and Ice interface.

### Features

- **Overlay**
  - Progress
  - Accuracy
  - Absolute accuracy
  - Music time
  - Map time
  - BPM
  - Judgement
  - Progress bar
  - Combo
  - Judgement strength
  - Best score
  - Play count
- **Key viewer**
  - Hand styles: 4-key, 8-key, 10-key, 12-key, 16-key, and 20-key
  - Foot styles: none, 2-key, 4-key, 6-key, 8-key, and 16-key
- **Resource changes**
  - Ball color
  - Default tile color
  - Rabbit appearance
  - Added logo

### Requirements

This mod requires [JALib](https://github.com/Jongyeol/JALib/releases).

### Installation

Download and run the [installer](https://github.com/Jongyeol/JipperResourcePack/releases/download/v1.0.0.0/JipperResourcePack.Installer.exe). It installs the mod automatically.
